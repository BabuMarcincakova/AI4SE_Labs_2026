This folder contains the Week 05 architecture-design task records for OneSport.

- `Task_1.md` and `Task_2.md` are the assignment instructions.
- `data/OneSport.txt` is the supplied OneSport requirements source.
- `OneSport_Task1_architecture_review.md` is the original Task 1 review.
- `OneSport_Task2_discussion_log.md` records the original ADR discussion,
  feedback, revision, and acceptance.
- `OneSport_ADR.md` is the original accepted architecture decision record.
- `with_skill/OneSport_Task1_with_skill.md` is the new Task 1 review produced
  using the architectural-review skill.
- `with_skill/OneSport_ADR_with_skill.md` is the accepted Task 2 ADR produced
  from the skill's decision step and ADR template.
- `with_skill/OneSport_with_skill_discussion_log.md` is the new Task 1
  and Task 2 synthesized discussion log, including ADR questions, answers, and
  decisions.
- `Task3_Skill_Comparison_Report.md` compares the original and new records.

The `with_skill` files are the outputs of the skill-guided run. The comparison
report records the earlier state in which the ADR was not yet present; the ADR
and appended Task 2 log now complete that run.
